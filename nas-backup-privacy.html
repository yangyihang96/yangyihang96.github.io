Xiaomi NAS Backup — Privacy

Last updated: 24 September 2026. This is a personal backup utility for its owner.

About this utility

Data used

The utility reads files from a designated folder on the owner's NAS and uploads them to the owner's Google Drive. It requests the Google Drive drive.file permission, which limits its access to files and folders used or created through this application. It does not request access to Gmail, contacts, or unrelated Drive files.

Storage and sharing

Backup files stay in the owner's Google Drive. The OAuth credential stays on the owner's NAS with restricted local file permissions. The utility does not sell data, show ads, or send backup files to other services. Operational status and errors are recorded locally on the NAS.

Retention and control

Deleting a file from the NAS source folder does not delete its cloud backup. Replaced cloud backup files are kept in a separate history folder. The owner can revoke the application's Google access in Google Account settings; revocation stops future transfers but does not automatically delete existing cloud files.
